# pandaren-ice-strike-filter

Loot-фильтры PoE2 (патч 0.5.5 Forbidden Rites) для владельца **PandarenDeepRover** (Monk, Ice Strike / Flicker-CI Invoker) + его соратницы **Чародейки Ткачи бурь** (билд «Плетение Молний»: мана/молния/CoC-криты).

**Три фильтра, все XCOMPACT** (надписи лута макс 28pt — под малый монитор, решение владельца 09.11.2026). Устаревшие версии v1/v2/v3/v5/v8 и NeverSink-зеркало удалены из репо (история — в git и в релизах до v1.9.0 включительно).

## Лестница тиров по ценности (v9.2/v7.2/currency v1.6, 13.11.2026)

Все три фильтра работают по единой именованной лестнице: **одинаковый звук в любом фильтре = одинаковый тир**. Цены — poe2-kit (Forbidden Rites, 11.11).

|---|---|---|---|---|---|
| T0 | «ЗЕРКАЛО» | ≥10 000 | 5/300 | 255 255 255 / 255 255 0 / 200 0 0 | Yellow / 0 Yellow Star |
| T1 | «ЛЕГЕНДА» | 300–10 000 | 4/300 | 255 220 220 / 255 60 60 / 140 0 0 | Red / 0 Red Star |
| T2 | «МЕГА» | 80–300 | 6/300 | 255 240 180 / 255 130 0 / 150 60 0 | Orange / 0 Orange Star |

Три канала сигнала:
- **ЦЕННОСТЬ** — валюта/уники/джевелы: цвет и звук строго по тиру (T0: Mirror, Temporalis; T1: Hinekora, Pinnacle Keys, Time-Lost, Mageblood, Headhunter, Morior; T2: Fracturing, Perfect Chaos, Flawless/Pure Breachstone, Wombgifts, Inscribed Ultimatum; T3: Divine, Perfect Exalted, Annul, Perfect Jeweller, Perfect Augmentation, эссенции, топ-омены, Uncut 18+, Waystones T15/16; T4: ординарные орбы, Trial Coins, Vault Keys, Logbooks, Map Fragments, сплинтеры 15+).
- **ВЛАДЕЛЕЦ** (только v9/парный дуэт) — базы гира и билдовые руны: роза = Чародейка, зелёный/сталь = Invoker. Цвет на полу = чей лут.
- **КАТЕГОРИЯ** — ключи/карты/гемы/квест: фирменный цвет сохранён, звук = тир ценности; формы иконок: Moon = гемы, Triangle = бижутерия.

Ключевые исправления v9.2/v7.2: Divine/P.Exalted больше не звенят как Mirror (T3 «ЦЕННЫЙ»); Fracturing/P.Chaos — T2; каждое правило проверено кросс-валидатором (синтаксис по офиц. справочнику + одинаковый звук на один BaseType во всех файлах).

## Установка (PoE2)

1. Скачай нужный `.filter` и скопируй в (НЕ в `onlinefilters`!):
   ```
   %userprofile%\Documents\My Games\Path of Exile 2\
   ```
2. В игре: `Escape → Options → Game/UI → Loot Filter` → выбери фильтр.
3. Если правил файл вручную — нажми **Reload** в списке (игра не перезагружает фильтр сама).
4. Рекомендуется задать горячую клавишу выделения дропа (Key Pickup / Use Bound Key), чтобы не зажимать Alt/пробел.
